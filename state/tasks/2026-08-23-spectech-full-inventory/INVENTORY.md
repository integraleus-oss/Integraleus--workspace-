## Важные прошлые решения

- Домены разведены по роли: корпоративный портал и коммерческий лидогенератор.
- Astro и PHP/MySQL ЛК остаются независимыми.
- Alpha-терминология проходит обязательный guardrail.
- Production-релизы: backup → выборочная загрузка → smoke → evidence; без delete и без `/lk/**`.
- Preview должен быть закрыт `noindex`.
- Публикация только после явного одобрения.

## Риски и несогласованности

1. У `specialtechnology.ru` большой незакоммиченный diff; его происхождение нужно классифицировать постранично.
2. Активный Astro-исходник лежит внутри transfer-снимка, а не в нормальном каноническом project source root.
3. Project management folder не является Git-репозиторием.
4. Старый HTTP deploy endpoint и ключ, упомянутый в README, должны считаться скомпрометированными и быть заменены.
5. SSH к shared hosting недоступен, но это не блокер при рабочем FTPS/панели.
6. ЛК содержит персональные данные; его БД, uploads и backup нельзя включать в CMS, Git или внешние сервисы.
7. WordPress добавит новый компонент, но не должен становиться runtime-зависимостью публичных страниц.
